unchanged when the superseded eagle v1/v2 concept folders were removed. The user associated
it with the [Gamification app inspiration](https://dribbble.com/shots/26419689-Gamification-app).

It informed flat fills, dot eyes, soft outlines, and cheek blush. It is reference material,
not an original KAIRO deliverable, a canonical asset, or an image to bundle in the app.
